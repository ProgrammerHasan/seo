# Sitemaps

You can generate XML sitemaps dynamically, save them as static files, or use the built-in Artisan command.

---

## Basic Sitemap

```php
use ProgrammerHasan\Seo\Facades\Seo;

$xml = Seo::sitemap()
    ->add('https://example.com')
    ->add(
        loc: 'https://example.com/about',
        lastmod: now()->toAtomString(),
        changefreq: 'monthly',
        priority: 0.5
    )
    ->add('https://example.com/contact')
    ->toXml();
```

---

## Dynamic `/sitemap.xml` Route

Add this to `routes/web.php`:

```php
use Illuminate\Support\Facades\Route;
use ProgrammerHasan\Seo\Facades\Seo;

Route::get('/sitemap.xml', function () {
    return response(
        Seo::sitemap()
            ->add(url('/'))
            ->add(url('/about'))
            ->add(url('/contact'))
            ->toXml(),
        200,
        ['Content-Type' => 'application/xml']
    );
});
```

Then visit:

```txt
https://your-domain.com/sitemap.xml
```

## Add Model URLs

Your model should have a `url()` method:

```php
public function url(): string
{
    return route('posts.show', $this);
}
```

Then add all model URLs:

```php
use App\Models\Post;
use ProgrammerHasan\Seo\Facades\Seo;

$xml = Seo::sitemap()
    ->add(url('/'))
    ->addModel(Post::class)
    ->toXml();
```

You can also pass a collection:

```php
$xml = Seo::sitemap()
    ->addModel(Post::published()->get())
    ->toXml();
```

If your model uses a different method name, pass it as the second argument:

```php
$xml = Seo::sitemap()
    ->addModel(Post::class, 'seoUrl')
    ->toXml();
```

## Add Last Modified Date

```php
$xml = Seo::sitemap()
    ->add(
        loc: 'https://example.com/about',
        lastmod: now()->toAtomString()
    )
    ->toXml();
```

You can also include `changefreq` and `priority`:

```php
$xml = Seo::sitemap()
    ->add(
        loc: 'https://example.com/about',
        lastmod: now()->toAtomString(),
        changefreq: 'weekly',
        priority: 0.8
    )
    ->toXml();
```

## Image Sitemap

```php
$xml = Seo::sitemap()
    ->image('https://example.com/post', [
        'https://example.com/image.jpg',
        'https://example.com/cover.jpg',
    ])
    ->toXml();
```

---

## Video Sitemap

```php
$xml = Seo::sitemap()
    ->video('https://example.com/video', [
        [
            'title' => 'Demo video',
            'thumbnail' => 'https://example.com/thumb.jpg',
        ],
    ])
    ->toXml();
```

---

## News Sitemap

```php
$xml = Seo::sitemap()
    ->news('https://example.com/news', [
        'name' => 'Example News',
        'language' => 'en',
        'title' => 'News title',
    ])
    ->toXml();
```

---

## Mixed Sitemap

```php
$xml = Seo::sitemap()
    ->add('https://example.com')
    ->add('https://example.com/about')
    ->image('https://example.com/post', [
        'https://example.com/image.jpg',
    ])
    ->video('https://example.com/video', [
        [
            'title' => 'Demo video',
            'thumbnail' => 'https://example.com/thumb.jpg',
        ],
    ])
    ->news('https://example.com/news', [
        'name' => 'Example News',
        'language' => 'en',
        'title' => 'News title',
    ])
    ->toXml();
```

---

## Save Sitemap File

```php
Seo::sitemap()
    ->add('https://example.com')
    ->add('https://example.com/about')
    ->save(public_path('sitemap.xml'));
```

---

## Sitemap Index

Use a sitemap index when you have multiple sitemap files.

```php
Seo::sitemap()
    ->index('https://example.com/sitemap-posts.xml')
    ->index('https://example.com/sitemap-products.xml')
    ->save(public_path('sitemap.xml'));
```

---

## Generate via Artisan Command

```bash
php artisan seo:sitemap
```

---

## Add Sitemap to `robots.txt`

```php
use ProgrammerHasan\Seo\Facades\Seo;

$content = Seo::robots()
    ->allow('/')
    ->sitemap(url('/sitemap.xml'))
    ->toString();
```

Example route:

```php
use Illuminate\Support\Facades\Route;
use ProgrammerHasan\Seo\Facades\Seo;

Route::get('/robots.txt', function () {
    return response(
        Seo::robots()
            ->allow('/')
            ->sitemap(url('/sitemap.xml'))
            ->toString(),
        200,
        ['Content-Type' => 'text/plain']
    );
});
```

---

## Recommended Usage

```txt
Small websites      → dynamic /sitemap.xml route
Large websites      → static sitemap.xml generated by command
Multiple resources  → sitemap index
SEO serious sites   → add sitemap URL inside robots.txt
```
