# OpenGraph

```php
Seo::title('Product page')
    ->description('Product description')
    ->image('https://example.com/product.jpg')
    ->type('product')
    ->og('locale', 'en_US')
    ->og('site_name', 'Example Store');
```

Common keys:

- `title`
- `description`
- `image`
- `type`
- `url`
- `site_name`
- `locale`
